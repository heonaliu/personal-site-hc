# Heona Website

## What:
- This is a personal website with some of my projects, my artworks, and general about me. Along with a contact card.

## Purpose of Site:
- This site was made by Heona as a way to create something personal as well as practicing the basics like HTML and CSS since I haven't practiced this in a very long time. I also wanted to create a site from basic HTML and CSS from scratch and see what I could do.

## How I Made This Site:
- I created this site with basic HTML, CSS.
- I also used Font-Awesome libraries to get the icons --> [Font-Awesome](https://cdnjs.com/libraries/font-awesome)
- The artworks on the site and projects are made by me in the past

## Challenges I Faced:
- When writing the Navbar, I connected the styles.css with the html and said that the a tags had to have no decoration. However, when I put text with an "a" tag it still showed underline (meaning there was decoration). I realized later that this is due to a typo in the stylesheet link (I typed style.css rather than styles.css). There was nothing wrong with my styles.css file - it was the linking that was the issue.
- After creating the navbar, I figured that when I made the window smaller, the navbar icons would collapse very poorly. It was necessary to make it mobile responsive when the window became too small.
- Creating the CSS on my own. I had to utilize my knowledge of classes and parent child hierarchy when applying styles. This wasn't easy because there are so many factors that go into css
- When adding images to the arts section, I encountered an issue where I couldn't just have set heights and widths because each image is different dimensions. In order to solve this, I set a max height and max width rather than saying "max height: 300px" for example. Then I put object contain so that anything extra wouldn't overflow

## What I'm Most Proud of:

Making it my own, I added my own elements -- like my art works, and doing the styling entirely on my own for the projects and the arts page! This project was a great refresher on classes and styling and media queries.
